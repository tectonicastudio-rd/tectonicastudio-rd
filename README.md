### 🚀 Nuestro primer software: **CAM3D**

**CAM3D** convierte el teléfono en un escáner 3D de obra. Con IA y realidad aumentada captura un espacio, reconstruye muros, alturas y áreas, y entrega planos acotados y modelos 3D listos para SketchUp, Revit, AutoCAD, 3ds Max y Maya.

| | |
|---|---|
| 🤖 **IA 3D** | Guía por voz y flechas hasta capturar el espacio al 100 %. |
| ⚙️ **Automático** | Muros, alturas, áreas y planos acotados sin dibujar. |
| 🧊 **Taller 3D** | Push/pull, cortes, booleanas, escalado y cotas. |
| 📤 **Exporta** | SketchUp · Revit · AutoCAD · 3ds Max · Maya · DXF · PDF · OBJ · LAS · PLY |
